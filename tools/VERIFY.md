# Facts to check against the manual

The bank was reviewed twice without the PRINCE2 7 manual in hand: once for answer
shape (length, structure, spelling, duplicates) and once question by question for
factual and internal consistency. A question was changed when it contradicted another
question, carried a distractor that was arguably also correct, or had an answer the
bank's own explanations did not support. Nothing below could be settled that way.
Web sources are exam-prep sites, not the official text, so treat them as hints only.

Exam-prep sources agree; the RACI in ch13-028 and ch18-024 has the project manager responsible, which may be compatible. | Confirmed against the manual (p.223): the project executive develops it, consulting the senior user if appointed. |
